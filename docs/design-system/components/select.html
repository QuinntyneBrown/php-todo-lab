Select

A select picks one value from a known list inside a form. It is the native control with the system's field styling and a drawn chevron.

WCAG 2.2 AAStatus: readyNot used in v1Native <select>

Overview

Use a select for five or more options inside a form, where the choice is submitted. For two to four options that change the view immediately, use a segmented control, as the All / Active / Done filter does; for two to four options in a form, use a radio group so every option is visible.

Not used in v1: the only choice in the product is the filter. Keep the native element; build a custom listbox only when native cannot do the job, then follow the APG Listbox.

Anatomy

  1. LabelVisible <label for>.
  2. Fieldselect.input with native appearance removed; same edge, radius and heights as the text field.
  3. Chevron.select::after: two 2px strokes in --color-fg-muted; decorative.

Variants

The placeholder option is disabled and selected with an empty value, so a required select cannot be submitted unchanged.

Sizes

Same size modifiers as the text field.

States

VariantDefaultHoverFocusInvalidDisabled
Select

There is no read-only select; show the value as text instead.

Both themes

color-scheme in each theme makes the native option list follow the theme.

Responsive behaviour

  • Full width of its container; on phones the OS picker opens, which is why the native element is preferred.
  • Text stays at least 16px so iOS does not zoom.

Theming

Uses the text field's --input-* tokens; the chevron reads --color-fg-muted. The option list is drawn by the browser and follows color-scheme.

Accessibility

Role and pattern

Native <select> (combobox/listbox semantics come for free). Changing it never submits or navigates on its own (3.2.2).

Keyboard

KeyAction
TabInto and out of the select.
↑ / ↓, lettersChange the value (type-ahead by first letter).
Alt+↓, SpaceOpen the list; Esc closes it.

Focus

Accent edge plus halo, as the text field.

Labelling

Visible label with for; errors via aria-describedby.

Contrast

Value on surface
Edge on card
Chevron on surface

Motion

Edge transition only; none under reduced motion.

Touch

44px default; the OS picker handles touch.

Content

  • Label with a noun or short verb phrase: "Sort tasks".
  • Options in sentence case, in a logical order (not alphabetical by default); placeholder starts with a verb: "Choose a list".
