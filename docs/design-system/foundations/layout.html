Foundation · Layout

Layout

One centred column that grows from full width to 640px, five breakpoints from L2-027, and a 4/8/12-column grid for everything else.

WCAG 2.2 AAStatus: stableSource: tokens/tokens.css

Overview

Tasks is one screen: a single centred column holding the header, an optional offline notice, the task card and a toast region (L2-022, L2-027). The layout tokens describe that column and the breakpoints it reacts to, and also a 4/8/12-column grid for documentation and any future multi-column screen. Layout is mobile first: XS is the base style and min-width queries add the rest (D18).

Breakpoints

The breakpoints come from L2-027. Custom properties cannot be used inside @media, so the values are repeated in queries by convention, always in rem so they follow the user's font size.

NameTokenFromQueryWhat changes (L2-027)
XS(base)0—Full-width column, 16px gutters, 48px ring, filter spans the full width, Add task shows its icon only.
SM--layout-breakpoint-sm (576px)(min-width: 36rem)Column up to 560px, centred; 56px ring; filter counts and the Add task label appear.
MD--layout-breakpoint-md (768px)(min-width: 48rem)Column 640px; 40px above the header.
LG--layout-breakpoint-lg (992px)(min-width: 62rem)Column stays 640px, offset 8vh from the top; the layout does not stretch.
XL--layout-breakpoint-xl (1200px)(min-width: 75rem)Same as LG.
2XL--layout-breakpoint-2xl (1440px)(min-width: 90rem)Documentation only (D22).

Usage

  • Read --layout-columns, --layout-gutter and --layout-margin instead of writing a media query; the tokens already change at MD and LG.
  • Write breakpoints mobile first with min-width in rem; the mocks' max-width: 575.98px overrides were rewritten (D18).
  • Use 100dvh for full-height layouts and env(safe-area-inset-bottom) for anything fixed to the bottom.
  • The column never stretches past 640px, even at 1920px (L2-027.4).

Accessibility

  • Reflow: everything works at 320px CSS width without two-dimensional scrolling (WCAG 1.4.10, L2-027.5).
  • DOM order is visual order at every breakpoint; layout changes never reorder controls.
  • Fixed elements (the toast) never cover focus: the safe-bottom padding keeps the last row scrollable above it (WCAG 2.4.11).
