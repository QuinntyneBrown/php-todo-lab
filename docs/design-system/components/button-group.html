Button group

A segmented control picks one of a few views. In Tasks it is the All / Active / Done filter: three toggle buttons, each with its count, and a raised indicator that slides to the selection.

WCAG 2.2 AAStatus: stableUsed in v1role="group" + aria-pressed

Overview

Use a segmented control when two to four options filter or switch the same content and exactly one is always selected. The filter changes which tasks are listed and mirrors the choice in the URL (?filter=active, L2-006); it does not navigate.

  • Use tabs instead when each option shows a different panel of content.
  • Use radio buttons inside a form, where the choice is submitted rather than applied at once.
  • Use separate buttons when the options are actions rather than views.

The toolbar is the row that holds the filter and Clear completed, between the composer and the list.

Anatomy

  1. Indicator.segmented__indicator: raised surface, --shadow-1, slides with transform; aria-hidden.
  2. Option.segmented__option: a toggle button with aria-pressed, 44px tall.
  3. Count.segmented__count: 14px tabular numerals; hidden below 576px but always in the accessible name.
  4. Track.segmented: sunken pill, 4px inset, max 340px from SM up.

Variants

Segmented (single select)

Three options (default) and two (.segmented--2). The indicator position comes from which option is pressed, using :has(); no script sets it.
HTML
<div class="segmented" role="group" aria-label="Show tasks">
  <span class="segmented__indicator" aria-hidden="true"></span>
  <button class="segmented__option" type="button" aria-pressed="false" aria-label="All, 5">All <span class="segmented__count">5</span></button>
  <button class="segmented__option" type="button" aria-pressed="true" aria-label="Active, 3">Active <span class="segmented__count">3</span></button>
  <button class="segmented__option" type="button" aria-pressed="false" aria-label="Done, 2">Done <span class="segmented__count">2</span></button>
</div>

Toolbar composition

.toolbar: filter left, Clear completed right; below 576px they wrap onto two rows. It is a plain row, not role="toolbar", because Tab (not arrows) moves between its controls.

Sizes

Medium (44px options) is the product size. Compact (36px, .segmented--compact) is for documentation chrome and dense settings, never the product (L2-028.1).

Option heights --target-comfortable (44px) and --control-height-sm (36px).

Both themes

In dark the indicator uses --color-bg-surface-raised, which is lighter than the track, so the selection reads at a glance (D9).

Responsive behaviour

  • XS (< 576px): the group spans the full width of the card (L2-027.1), counts are hidden, and Clear completed wraps under it, right-aligned.
  • SM and up (≥ 576px): the group is at most 340px (21.25rem), counts show, and the toolbar holds both controls on one row.
  • Options share the width equally (repeat(var(--segmented-count), 1fr)), so labels never shift when counts change; counts use tabular numerals.
  • At 200% zoom the group still fits a 320px viewport; labels are one short word each.

Theming

The track reads --color-bg-surface-sunken, the indicator --color-bg-surface-raised and --shadow-1, labels --color-fg-muted (resting) and --color-fg-default (selected or hovered). Component tokens --segmented-count, --segmented-index and --segmented-inset set the geometry; change the count with .segmented--2 / .segmented--4 or set --segmented-count directly.

Accessibility

Role and pattern

A role="group" with aria-label="Show tasks" containing toggle buttons with aria-pressed (APG Button, toggle), as L2-029.4 allows. It is not a tablist: there are no panels and the list below is the same region.

Keyboard

KeyAction
Tab / Shift+TabMoves through each option, then to Clear completed.
Enter, SpaceSelects the focused filter; the URL updates and focus stays on the button.

Focus

The shared ring on the focused option, drawn outside the pill. Focus never moves to the list when the filter changes.

Labelling

Each option's name includes its count: aria-label="Active, 3" (L2-029.4), so the count is announced even when it is hidden below 576px. The indicator is aria-hidden; selection is announced as "pressed".

Contrast

Unselected label on track
Selected label on indicator
Focus ring on track
Clear completed on card

Selection is never colour alone: the pressed option is semibold, darker and sits on the raised indicator (L2-030.6).

Motion

The indicator slides with transform over --duration-base (200ms, ease-out; the mock's 220ms, D15). Reduced motion makes it jump.

Touch

Options are 44px tall and at least a third of the card wide at XS.

Content

  • One word per option, sentence case: "All", "Active", "Done". Use the same words in the URL (?filter=active) and in the empty states ("All clear", "Nothing completed yet").
  • Counts are plain numerals, no brackets.
  • The group label describes the choice, not the control: "Show tasks".
