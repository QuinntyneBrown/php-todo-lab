Link

A link moves to another place: another page, a section, a document. It is always underlined and always an <a href>.

WCAG 2.2 AAStatus: stableNot used in v1

Overview

Use a link when activating it navigates and changes nothing. If it changes data (adds, clears, deletes, retries), it is a button, even when it should look quiet; use .btn--ghost or .btn--link for that.

The v1 screen has no navigation (L2-022: one screen), so the product UI has no links. The mocks use links only in their review notes ("All mocks"), and these documentation pages use them throughout; both follow this page. Links will appear when the product gains help or settings pages.

Anatomy

  1. TextSays where it goes. Inherits the surrounding size; standalone links are semibold.
  2. Underline1px at rest, 2px on hover, 3px below the baseline. Never removed inline (1.4.1).
  3. Trailing icon (optional)1em, aria-hidden: an arrow for standalone links, the external mark for new tabs.

Responsive behaviour

  • Inline links wrap with their sentence; long URLs never appear as link text, so nothing overflows at 320px.
  • Standalone links keep a 24px minimum target (--target-min) at every breakpoint; on phones, give lists of standalone links 8px between them.

Theming

Links read --color-fg-link and --color-fg-link-hover. In light these are sea-700 and sea-800, darker than the accent fill, because the accent itself is only 4.19:1 on the page canvas (D3). In dark they are sea-400 and sea-300.

Accessibility

Role and pattern

Native <a href> (APG Link). No role="link" on other elements.

Keyboard

KeyAction
Tab / Shift+TabMoves focus between links.
EnterFollows the link. (Space scrolls the page; it does not activate links.)

Focus

The shared 2px ring at a 2px offset, with a 4px radius so it hugs the text.

Labelling

The text is the name and must make sense alone (2.4.4): "Keyboard shortcuts", not "here". External links add visually hidden "(opens in a new tab)".

Hovered link

The underline, not the colour, identifies links (1.4.1).

Motion

None.

Touch

Standalone links are at least 24px tall; inline links rely on the 2.5.8 inline-text exception.

Content

  • Name the destination, in sentence case: "Keyboard shortcuts", "All mocks".
  • Never "click here", "read more" or a bare URL.
  • Put the link on the words that describe the destination, not on a whole sentence.
