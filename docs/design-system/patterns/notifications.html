Pattern

Notifications

Each kind of message has one place and one lifetime, so people learn where to look.

Overview

Four surfaces tell the person something happened. Each has a fixed job, place and lifetime, so the same kind of message always appears in the same place:

  • Toast: the result of an action they just took, at the bottom centre. Undo toasts last 6 s; error toasts state what did not happen.
  • Banner (flush danger alert): the list could not load, inside the card in place of the list.
  • Notice (compact warning alert): a condition of the whole app (offline), above the card.
  • Field message: a problem with what they typed, under the field.

Plus an invisible fifth: the polite live region that announces every change (see Feedback and loading). There is no notification centre and no badge count.

One toast at a time: a new toast replaces the current one (a second delete replaces the first Undo). Errors never auto-dismiss on a timer; they leave when replaced or when the person acts again.

Responsive behaviour

  • Toast: bottom centre at every breakpoint (not bottom-right), 16px from the bottom plus env(safe-area-inset-bottom), full width minus gutters up to 420px (L2-028.5).
  • The list reserves --layout-safe-bottom (96px + safe area) so the toast never hides the last row.
  • Notice and banner wrap text; the banner's Try again button moves under the text on narrow cards.

Accessibility

  • Toasts never take focus (L2-031.5); Undo is reachable by Tab and by Ctrl/Cmd+Z. The 6 s timer pauses while the toast or its button has focus or hover (WCAG 2.2.1).
  • Error toasts use role="alert", others role="status" (L2-031.2). Do not also push the same text into the live region, or it is read twice.
  • The toast's focus ring uses the action colour so it stays visible on the inverse surface in both themes.
  • Toasts and notices are colour + icon or verb + text; none relies on colour alone.

Content

  • Success: object + past participle, no full stop: "Task deleted", "3 tasks cleared" (singular for 1).
  • Failure: "Couldn't" + verb + object + full stop, then a next step only when there is one: "Couldn't add that task. Try again."
  • Action button: one verb: "Undo", "Try again".
  • No "Oops", no "Sorry", no exclamation marks (L2-025).
