Sidebar navigation

Overview

Sidebar navigation lists the places in an app and marks where you are. It is visible beside the content on wide screens and moves into a drawer on narrow ones.

Not used in v1. The product is one screen with no routes beyond / (L2-022), so there is nowhere to navigate. The pattern is extracted from this documentation's own sidebar so a future multi-list version starts from a tested component (D22).

  • Use it when an app has five or more top-level destinations that people move between often.
  • Use the segmented control for switching views of one list (All / Active / Done) and tabs for sections of one page.

Anatomy

  1. Group heading<summary>, overline type, collapses its group.
  2. Current itemaria-current="page"; accent-subtle fill, accent text, semibold.
  3. ItemIcon (20px) + label, 44px tall, --radius-md.
  4. Count badge (optional)Pushed to the end; labelled with its meaning.

Responsive behaviour

  • LG and up (≥ 992px): visible beside the content, sticky, full height, --layout-sidebar-width (16rem).
  • Below LG: hidden behind a menu button in the top bar (aria-expanded + aria-controls) and shown as a left drawer; groups other than the current one start collapsed.
  • The collapsed icon rail is for MD screens where content needs the width; it keeps tooltips with the item names.

Theming

Reads --color-bg-surface, --color-border-default, --color-fg-muted, --color-fg-subtle, --color-bg-subtle, --color-accent-subtle and --color-fg-accent. Override --layout-sidebar-width to change the width.

Accessibility

Role and pattern

A <nav aria-label> landmark with lists of links, the APG Disclosure pattern for collapsible groups (native <details>), and aria-current="page" on the current link. It is not a menu or a tree; arrow keys are not used.

Keyboard

KeyAction
Tab / Shift+TabMoves through group headings and links in order.
EnterFollows a link.
Enter, Space on a headingOpens or closes the group.

Focus

Shared 2px ring at a 2px offset around the 44px item. When the drawer opens, focus moves to the current item; Esc closes the drawer and returns focus to the menu button.

Labelling

Each <nav> has a distinct aria-label. In the collapsed rail the visible label is hidden visually but kept in the DOM, so the link name does not change. Count badges carry aria-label="3 left", not a bare number.

Motion

The chevron rotates over --duration-fast; the drawer slides in over --duration-slow. Both are instant with reduced motion.

Touch

Items are 44px tall with 2px between them; the whole row is the target.

Content

  • Item labels are nouns in sentence case ("All tasks", not "View all tasks").
  • Group headings are one or two words.
  • Counts are numbers only, with the meaning in the accessible name.
