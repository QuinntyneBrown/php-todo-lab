Foundation · Shape

Shape

Five radii plus full, growing with the element, and three border widths.

WCAG 2.2 AAStatus: stableSource: tokens/tokens.css
  • Overview
  • Radii
  • Which radius
  • Borders

Overview

Tasks is soft-cornered: a 20px card, 12px inputs and buttons, pills for anything that toggles. The mocks used nine distinct radii (4, 7, 8, 10, 12, 14, 20px, 999px, 50%); they were reduced to five steps plus full (D10), and the rule is that radius grows with the element.

Border widths

Three widths. Inputs keep the mocks' 1.5px edge; checkboxes use 2px so the ring reads at 24px (the 26px box snapped to 24px, D17).

--border-width-hairline
--border-width-control
--border-width-thick

Usage

  • Nested corners are concentric: inner radius = outer radius − padding (toast 16px − 4px = Undo 12px).
  • Never mix pill and square corners in one control group.
  • Do not round only some corners except where an element is attached to an edge (input groups, bottom sheets).

Accessibility

  • Shape never carries meaning alone: round checkboxes (tasks) and square checkboxes (forms) differ only in context, and both expose the native checkbox role.
  • Focus outlines follow the element's radius, so the 2px ring stays visible around pills and round buttons.
