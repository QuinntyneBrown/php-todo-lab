Tasks

Design mocks for the one-screen to-do app. Each page is a single state you can link to; the prototype puts them all together. Specs: docs/specs/L2.md, L2-001 to L2-031 and L2-042.

Theme

Prototype

  • Interactive prototypeAdd, complete, edit, delete and undo, filter, clear completed. Switch data states at the bottom.

Screens

  • LoadedFive tasks, newest first, two done
  • LoadingThree skeleton rows, composer already usable
  • EmptyFirst run: nothing here yet
  • All doneEvery task ticked: full ring, "All done"
  • Load errorInline banner with Try again; composer still works
  • OfflineNon-blocking notice while the browser is offline
  • 500-task limitLimit reached; typed text is kept
  • Long titles200 characters, emoji, CJK and URLs wrap cleanly
  • Deleted, with undoRow gone, "Task deleted" toast with Undo

Filters

  • Active filterOnly the three active tasks
  • Active filter, all clear"All clear. Nothing left to do."
  • Done filterOnly the two completed tasks
  • Done filter, empty"Nothing completed yet."

Inline states

  • Composer statesDefault, focus, counter, limits and validation
  • Row statesHover, focus, pending, completion frames, editing, leaving
  • Toolbar statesFilter pill positions, counts and Clear completed

Notifications

  • NotificationsEvery toast, banner, field message and announcement

Dialogs

  • None, by designL2-022 keeps the app to one screen with no modals. Destructive actions are undoable from a toast instead of confirmed in a dialog.
