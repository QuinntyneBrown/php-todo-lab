# Support

## How to get help

php-todo-lab is maintained on a best-effort basis by volunteers. There is no
paid support.

- **Setup and usage questions:** start with the [README](README.md), then the
  [backend](backend/README.md) and [frontend](frontend/README.md) READMEs.
- **Bugs:** search the
  [existing issues](https://github.com/QuinntyneBrown/php-todo-lab/issues)
  first. If your bug isn't there, open a new issue with the bug report
  template.
- **Feature ideas:** open an issue with the feature request template.
- **Security issues:** don't open an issue. Follow [SECURITY.md](SECURITY.md).

## Before you open an issue

Please include:

- your operating system,
- your PHP, Composer, Node.js, and MySQL versions,
- the commit you're running, from `git rev-parse --short HEAD`, and
- the full output of the failing command.
