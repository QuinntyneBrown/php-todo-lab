Execution model

ASP.NET Core

  • One long-lived Kestrel process
  • Container built once at startup
  • Singletons and statics live for days
  • Compiled to assemblies

PHP (traditional)

  • Shared-nothing: every request starts empty
  • Framework boots on every request
  • Statics die with the request
  • No compile step: files loaded on demand

Consequences

  • No in-process cache unless you reach for one explicitly
  • A static property does not survive between requests
  • Boot cost is paid per request, so Laravel caches config and routes in production
  • Long-lived mode exists (Octane), but this repository does not use it

Composer and PSR-4: namespaces are folders

},
"autoload-dev": {

        "Tests\\": "tests/"
    }
}
  • Composer is PHP's NuGet; it also writes the autoloader
  • App\Actions\Todos\CreateTodo must live at app/Actions/Todos/CreateTodo.php
  • Namespace separator is a backslash
  • composer.lock is committed, like a lockfile should be

The mental model

A scripting language with a per-request lifecycle, loaded by convention from the file system, with a NuGet-like package manager.Everything else is closer to C# than you expect.

declare(strict_types=1)

backend/app/Actions/Todos/CreateTodo.php
<?php

declare(strict_types=1);

namespace App\Actions\Todos;

use App\Models\Todo;
use App\Repositories\TodoRepository;
  • Default PHP coerces: "5" becomes 5 for an int parameter
  • Strict mode throws a TypeError instead
  • Applies to calls made from that file, so it must be in every file
  • Enforced here by the formatter (Pint), not by review

Types on every signature

app/Actions/Todos/CreateTodo.php
public function handle(string $title): Todo
{
    return $this->todos->createWithinLimit($title, self::LIMIT);
}
app/Repositories/TodoRepository.php
/** The non-deleted todo with this id, if any. */
public function find(string $id): ?Todo;
  • Parameter, return, and property types are checked at runtime
  • ?Todo is nullable, like Todo? in C# but enforced when called
  • Union types exist (int|string), and mixed is the escape hatch

Docblocks are the generic type system

app/Actions/Todos/ClearCompletedTodos.php
/**
 * Soft-deletes every completed todo in one transaction (L2-017, L2-043).
 *
 * @return list<string> the ids deleted, so the client can undo
 */
public function handle(): array
{
    return $this->todos->deleteCompleted();
}
app/Repositories/TodoRepository.php
/**
 * Counts of all non-deleted todos.
 *
 * @return array{active: int, completed: int}
 */
public function counts(): array;
  • One array type: ordered, int- or string-keyed, and a value type
  • No List<T>: say list<string> in the docblock
  • Array shapes replace small DTOs: array{active: int, completed: int}
  • Larastan checks every docblock type. Treat them as mandatory.

A readonly class is your sealed record

PHP · app/Actions/Todos/CreateTodo.php 
final readonly class CreateTodo
{
    /** The most non-deleted todos the list may hold (L2-003). */
    public const int LIMIT = 500;

    public function __construct(private TodoRepository $todos) {}

    public function handle(string $title): Todo
    {
        return $this->todos->createWithinLimit($title, self::LIMIT);
    }
}
C# · the shape you already know 
public sealed record CreateTodo(ITodoRepository Todos)
{
    public const int Limit = 500;

    public Todo Handle(string title) =>
        Todos.CreateWithinLimit(title, Limit);
}
  • Constructor promotion (8.0), readonly classes (8.2), typed constants (8.3)
  • final is sealed; self:: reads the constant

match: the switch expression

app/Repositories/EloquentTodoRepository.php
public function list(TodoStatus $status): Collection
{
    $query = Todo::query()->orderByDesc('created_at')->orderByDesc('id');

    match ($status) {
        TodoStatus::All => null,
        TodoStatus::Active => $query->active(),
        TodoStatus::Completed => $query->completed(),
    };

    return $query->get()->toBase();
}
  • Strict comparison, no fall-through
  • Must be exhaustive: an unmatched value throws UnhandledMatchError
  • Returns a value, like C#'s switch expression
  • Prefer it over the old switch statement

Null handling and throw as an expression

app/Actions/Todos/DeleteTodo.php
/**
 * Soft-deletes the todo so it can be restored until it is purged (L2-015, L2-016).
 *
 * @throws TodoNotFound
 */
public function handle(string $id): void
{
    $this->todos->delete($this->todos->find($id) ?? throw new TodoNotFound($id));
}
  • ?? null coalescing, ?-> null-safe: the same ideas as C#
  • throw is an expression, so the not-found guard is one line in every Action that loads by id

Closures and callables

app/Repositories/EloquentTodoRepository.php
return DB::transaction(function () use ($title, $limit): Todo {
    if (Todo::query()->lockForUpdate()->count() >= $limit) {
        throw new TodoLimitReached($limit);
    }

    return Todo::query()->create(['title' => $title]);
}, attempts: 3);
app/Http/Requests/Api/V1/RestoreTodosRequest.php
public function ids(): array
{
    return array_values(array_map(strtolower(...), $this->array('ids')));
}
  • fn ($x) => ...: expression lambda, captures scope automatically
  • function () use ($a, $b): captures only what you name, by value
  • strtolower(...): first-class callable, the method-group conversion
  • attempts: 3: a named argument

Things to remember

  • Runtime: shared-nothing per request, no compile step, PSR-4 maps namespaces to folders
  • Types: strict_types in every file, typed signatures, docblocks checked by Larastan
  • Constructs: readonly classes are records, backed enums convert for free, match is the switch expression
  • Habits: ===, arrays are values, no static state
