Avatar

A person shown as a photo, initials or an icon, always alongside their name.

Overview

An avatar represents a person with a photo, initials or a generic icon. The to-do app has a single anonymous user and no accounts in v1, so avatars are not used; the component exists so a future shared-list or account feature starts from the system.

  • Use an avatar next to a person's name, or alone where space is tight and the name is in the accessible name.
  • Never use an avatar as the only way to tell people apart; pair it with the name.

Anatomy

  1. CircleInitials on --color-accent-subtle in --color-fg-accent, or a cropped photo.
  2. Status dot (optional)28% of the size, --color-success-icon with a surface-coloured ring.

States

Avatars are not interactive. When one is a link (for example to a profile) the link takes the shared focus ring; the avatar itself has no hover or disabled state.

Responsive behaviour

  • Sizes do not change with the viewport; pick the size for the context.
  • Groups show at most four avatars and then a count, at every width.

Theming

Reads --color-accent-subtle and --color-fg-accent (initials), --color-bg-subtle-hover (overflow), --color-success-icon (status) and --color-bg-surface for rings. Component token: --avatar-size.

Accessibility

Role and pattern

Decorative when the name is next to it (aria-hidden="true"); otherwise role="img" with the name as aria-label, or an <img alt>. No APG widget pattern applies.

Keyboard

KeyAction
TabNot focusable unless wrapped in a link or button.

Focus

The wrapping link draws the shared ring, rounded to the circle.

Labelling

Status dots are colour only, so the status goes in the label ("Leo Park, online"). Groups get one label listing the names and the overflow count.

Contrast

Initials on avatar
Overflow count

Motion

None.

Touch

A linked avatar must be at least 44px including padding; the 32px size is only used next to a name that is also the link.

Content

  • Initials: first letter of the first two words of the name, uppercase by style.
  • Photos are cropped square and centred on the face.
  • Labels use the person's name, never "avatar" or "profile picture".
