Typography

Bricolage Grotesque for the weekday and the count, Figtree for everything you read and type: nine sizes, four weights, fourteen roles.

Overview

Two faces: Bricolage Grotesque for the few display moments (the weekday, the count, empty-state titles) and Figtree for everything you read and type. Body stays at 16px, inputs at 18px so phones never zoom, and nothing goes below 12px. Sizes are rem, so the whole scale follows the reader's font-size setting.

Components use the role shorthands (font: var(--text-body)), never a raw size. The mocks used six distinct sizes and four line heights, several off any scale; they were snapped to a nine-step scale (D12, D14).

Measure

Prose is capped at --layout-measure (65ch, owned by Layout). Short supporting copy is narrower: the empty-state sentence is capped at 30ch so it breaks into a balanced one or two lines.

Toasts confirm what just happened and offer Undo. Errors say what went wrong and what to do next, and never apologise. One toast at a time, at the bottom centre, clear of the safe-area inset.

Responsive type

  • Only the display role is fluid: clamp(var(--font-size-3xl), 8vw, var(--font-size-5xl)), 30px at 320px wide, 52px from about 650px. It is the one place a long weekday ("Wednesday") must fit beside the progress ring at 320px.
  • Everything else uses fixed steps, so browser zoom and the user's font size scale it (WCAG 1.4.4); spacing does not grow with the viewport.
  • Inputs never drop below 16px at any breakpoint (L2-028.3); the scale's input size is 18px.
  • Long task titles wrap with overflow-wrap: anywhere; nothing truncates (L2-027.6).

Usage

  • Use font: var(--text-*); change only weight or size with the matching primitive when a role needs a variant (for example the selected filter at --font-weight-semibold).
  • Display face for at most one line per view, plus numerals and empty-state titles.
  • Tabular numerals (font-variant-numeric: tabular-nums) for every count that changes in place: the progress count, filter counts, the character counter.
  • Sentence case everywhere (L2-025); uppercase only through the overline role.

Accessibility

  • All sizes in rem; 200% zoom keeps every function (L2-030.3).
  • Line height 1.5 for body and titles; nothing clips with WCAG 1.4.12 text-spacing overrides (L2-030.4).
  • Minimum size 12px; muted and subtle text still pass 4.5:1 (see colour contrast).
  • 18px inputs avoid iOS focus zoom (L2-028.3).
