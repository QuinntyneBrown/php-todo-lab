Progress

How much is finished: the header ring that fills as tasks are completed, and a bar for longer operations.

WCAG 2.2 AAStatus: stableUsed in v1

Overview

Progress shows how much of something is finished. The product has one: the progress ring in the header, which fills as tasks are completed and closes with a tick when all are done (L2-007). Its number ("3 left", "All done") is the real information; the ring is a glance. The progress bar is the system's determinate and indeterminate indicator for longer operations; v1 does not need it (D22).

  • Use the ring only with its count next to it.
  • Use a bar when an operation takes more than a second and its progress is known.
  • Use a skeleton while content loads, and a spinner only for short waits on a single control.

Anatomy

  1. Count--text-stat (24px display, tabular figures): remaining tasks, or "All done".
  2. Label"left", 14px medium muted; hidden when all are done.
  3. TrackFull circle, 5-unit stroke, --color-border-default.
  4. FillArc from 12 o'clock, --color-accent, round caps; length from --progress (0–1).
  5. Done tickAppears in the centre at 100% with .progress-ring--complete.

Responsive behaviour

  • Ring: 48px below 576px, 56px from SM, via the component's own media query (L2-027.1).
  • The count and ring never wrap away from each other: .progress-summary is flex: none and the heading beside it shrinks instead.
  • Bars fill their container at every width; the label row wraps only if the label is very long.

Theming

The ring reads --color-border-default (track) and --color-accent (fill and tick). The bar exposes --progress-fill, set by its tone modifiers from --color-success-solid and --color-danger-solid. Both take --progress (0–1) as their only input, so a framework binds one number.

<div class="progress-ring" [style.--progress]="doneRatio()">…

Accessibility

Role and pattern

The ring is decorative (aria-hidden="true"); the count beside it is text, and changes are announced through the polite live region ("2 left", "All done", L2-007.5). The bar follows the APG Meter guidance for its role choice: an operation in progress uses role="progressbar" with aria-valuenow/min/max, or no value when indeterminate, and is labelled by its visible label.

Keyboard

Nothing to operate: the component is not focusable.

Focus

Neither indicator takes focus.

Labelling

Ring: none (hidden); the count is the accessible information. Bar: aria-labelledby pointing at the visible label.

Motion

The ring fill transitions over --duration-slow; the tick fades and scales in over --duration-base. Nothing animates on load (L2-024.1). The indeterminate bar loops and is replaced by a static half-tone bar under reduced motion.

Touch

Not interactive; no target size applies.

Content

  • Count what is left, not what is done: "3 left". At zero remaining with tasks present, say "All done" and hide "left".
  • Bar labels name the operation in the present tense ("Importing tasks"), switching to the result when finished ("Import complete").
  • Percentages are whole numbers with no space before %.
