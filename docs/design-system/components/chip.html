Chip

Overview

A chip is a compact, rounded control. Filter chips toggle an option on or off with aria-pressed; input chips show a value that can be removed; static chips label without acting. The mocks' launcher uses filter chips for its Match system / Light / Dark switch.

  • The product's task filter is a segmented control, not chips: exactly one of three is always selected and it shows counts.
  • Use chips for independent toggles or a small set of removable values; use a badge for a label nobody presses.

Anatomy

  1. Label16px medium, sentence case.
  2. Remove (input chips)36px round button, labelled "Remove <value>".
  3. Container44px tall, full radius, 1px --color-border-strong.

Variants

Filter chips: the launcher's theme switch. A pressed chip inverts to --color-bg-inverse.

Responsive behaviour

  • Chip rows use .cluster and wrap onto new lines at narrow widths; they never scroll horizontally.
  • Small chips are not used below MD; touch screens keep 44px chips (L2-028.1).

Theming

Reads --color-bg-surface, --color-border-strong, --color-bg-subtle (hover) and, when pressed, --color-bg-inverse/--color-fg-inverse (light chip on dark in the dark theme). Component token: --chip-height.

Accessibility

Role and pattern

Filter chips are toggle buttons (APG Button, aria-pressed) in a role="group" with a label. When exactly one must be on, prefer a radio group or the segmented control. Input chips are text plus a native remove <button>.

Keyboard

KeyAction
TabMoves to each chip (and each remove button).
Space / EnterToggles a filter chip or removes an input chip.
Backspace / DeleteOn a remove button: removes the value too.

Focus

Shared 2px ring with 2px offset, following the pill shape. After removing a chip, focus moves to the next chip's remove button, or the field that adds them.

Labelling

Chip text is the name; the group has aria-label or aria-labelledby ("Theme"). Remove buttons are "Remove <value>".

Motion

Background and colour change over --duration-fast; zeroed under reduced motion.

Touch

44px tall with an 8px gap; remove buttons are 36px inside the 44px chip.

Content

  • One to three words, sentence case: "Match system", "Light", "Dark".
  • Filter chips name the option, not the action ("Dark", not "Use dark").
  • Input chips show the value exactly as entered.
