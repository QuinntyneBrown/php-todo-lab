Breadcrumb

Overview

A breadcrumb shows where a page sits in a hierarchy and links to each ancestor.

Not used in v1. The product has one page and no hierarchy (L2-022). Documented for future nested lists (D22).

  • Use on pages three or more levels deep.
  • Do not use as the only navigation or for a linear flow.

Anatomy

  1. Ancestor linkUnderlined link, --text-body-sm, 24px minimum target.
  2. Separator"/" in --color-fg-subtle, generated by CSS so it is not read aloud.
  3. Current pagePlain text with aria-current="page".

Variants

  1. Home
  2. Lists

Full.
HTML
<nav class="breadcrumb" aria-label="Breadcrumb">
  <ol class="breadcrumb__list">
    <li class="breadcrumb__item"><a href="/">Home</a></li>
    <li class="breadcrumb__item"><span aria-current="page">Q4 budget</span></li>
  </ol>
</nav>

Responsive behaviour

  • MD and up: the full trail, wrapping onto a second line if needed.
  • Below MD with .breadcrumb--collapse: only the parent link, prefixed with ‹, as a back link.

Theming

Reads --color-fg-link, --color-fg-link-hover, --color-fg-default (current) and --color-fg-subtle (separator).

Accessibility

Role and pattern

APG Breadcrumb pattern: <nav aria-label="Breadcrumb"> containing an ordered list; the current page has aria-current="page".

Keyboard

KeyAction
TabMoves through the ancestor links.
EnterFollows the focused link.

Focus

Shared 2px ring around each link (rounded with --radius-xs).

Labelling

Separators are CSS-generated so they are not announced; the list structure gives position ("3 of 4").

Contrast

Link on page
Separator on page

Motion

None.

Touch

Links have a 24px minimum target height (WCAG 2.5.8) with 4px gaps plus the separator between them.

Content

  • Use each page's own title, in sentence case.
  • Do not repeat the current page's heading if it already appears directly below; keep it as the last crumb only.
