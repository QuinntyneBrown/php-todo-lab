Accessibility

Overview

Tasks meets WCAG 2.2 level AA in both themes (L1-009). Accessibility is built into the tokens (contrast-checked colour pairs, one focus ring, 44px targets, durations that vanish under reduced motion) and into every component page, whose #accessibility section answers the same seven questions. This page is the list of commitments and how they are tested.

Focus

Focus states forced with data-state="focus": ring on buttons and the checkbox, border plus halo on the input.

Ring on hovered row

Exactly one focus style for buttons, links and checkboxes, from components.css: outline: var(--focus-ring-width) solid var(--color-focus-ring); outline-offset: var(--focus-ring-offset) on :focus-visible, so mouse clicks do not show it. Text inputs replace the outline with an accent border and a 3px --shadow-focus halo (accent border ≥ 3:1). Inside the toast the ring takes the action colour so it stays visible on the inverse surface.

Perceivable

RequirementSCCommitment in Tasks
Text contrast1.4.3Body, label and secondary text ≥ 4.5:1 on every surface it sits on, in both themes. 74 pairs per theme live in tokens/contrast-pairs.json and are checked by check_contrast.py (L2-030.1).
Non-text contrast1.4.11Input and checkbox edges, the focus ring, the checked fill and status icons ≥ 3:1. The mock's --line-strong failed at 2.89:1 and the composer had no edge at all; both are fixed (D1, D2). Row dividers are decorative.
Use of colour1.4.1Completed tasks show a tick and a strike as well as muted text (L2-030.6); alerts pair colour with an icon and a sentence (D19); links are underlined.
Resize and reflow1.4.4, 1.4.10Sizes in rem; one column reflows to 320px; 200% zoom loses nothing (L2-030.3).
Text spacing1.4.12Rows and controls grow with content; no fixed heights on text (L2-030.4).
Images1.1.1Icons and empty-state art are aria-hidden; icon-only buttons carry aria-label.
Orientation and motion1.3.4, 2.3.3No orientation lock; reduced motion zeroes durations in the tokens (L2-024.2).
Input purpose1.3.5The composer is not personal data, so autocomplete="off"; future personal fields set autocomplete.

Operable

RequirementSCCommitment in Tasks
Keyboard2.1.1, 2.1.2Everything works with Tab, Enter, Space and Escape: Enter adds, Space toggles, Enter edits a title, Escape cancels an edit, Ctrl/Cmd+Z undoes. No traps.
Focus visible2.4.7, 2.4.11One ring on :focus-visible: --focus-ring-width of --color-focus-ring at --focus-ring-offset, ≥ 3:1 on every surface. Inputs show an accent border plus a 3px halo instead.
Focus not obscured2.4.11The toast sits in a reserved bottom area (--layout-safe-bottom), so it never covers a focused row.
Focus order2.4.3DOM order is visual order: header, composer, filter, Clear completed, rows. No positive tabindex. After delete, focus moves to the next row; after Undo it returns.
Target size2.5.8Every product control is 44 × 44px (--target-comfortable, L2-028.1).
Timing2.2.1The Undo toast holds 6 s, pauses while hovered or focused, and Ctrl/Cmd+Z is an alternative; error toasts persist until the next action.
Skip and landmarks2.4.1One main; a skip link where a page has content before it.
Titles and headings2.4.2, 2.4.6One h1: the date (L2-029.1).
Pointer cancellation2.5.2Actions fire on click, never on pointer down.

Component contract

Every component page documents, under #accessibility:

  1. Role and pattern: the native element or the WAI-ARIA APG pattern used.
  2. Keyboard: a table of keys and effects.
  3. Focus: where it starts, where it goes after an action, how the ring looks.
  4. Labelling: what is named, how, and what is announced.
  5. Contrast: the token pairs with live ratios in both themes.
  6. Motion: what animates and what reduced motion does.
  7. Touch: target sizes and hover alternatives.

Testing

  • python check_contrast.py tokens/tokens.css: every declared pair, both themes, exits 0.
  • python check_design_system.py docs/design-system: labels, names, alt text, landmarks, headings, links.
  • axe-core (Playwright) in every product state: loaded, empty, loading, error, editing, toast visible, both themes, zero violations (L2-030.5).
  • Keyboard only: add, complete, edit, cancel, delete, undo, filter and clear without a mouse.
  • Screen reader (NVDA + Firefox, VoiceOver + Safari): checkbox names, filter counts, live-region announcements, error alerts.
  • Zoom to 200% and 400%; apply the text-spacing bookmarklet; emulate prefers-reduced-motion, forced-colors and touch.
