Tooltip

A short description that appears on hover and focus. Never the only place information lives.

WCAG 2.2 AAStatus: readyNot used in v1

Overview

A tooltip is a short text label that appears next to a control on hover and on keyboard focus. It describes; it never contains links, buttons or anything you must read to complete a task.

Not used in v1. Every icon-only control in the product already has a visible meaning and an aria-label that includes the task title (L2-029.5: "Delete Call mom"), and on touch devices (most of v1's audience) hover tooltips never appear. The component is documented for future dense toolbars and keyboard-shortcut hints (D22).

  • Use for icon-only buttons on pointer-first screens and for shortcut hints ("Undo Ctrl Z").
  • Do not use for error messages, help text a person needs, or anything interactive: use an inline message or a dialog.

Anatomy

  1. Bubble--color-bg-inverse, --radius-sm, --text-body-sm, max 16rem.
  2. Arrow4px triangle pointing at the trigger.
  3. TriggerA focusable control; it points at the bubble with aria-describedby.

Sizes

Tooltips have one size; the bubble wraps at 16rem.

States

The bubble is hidden by default and shown when its anchor is hovered or contains focus. It appears after a 300ms delay (1.5 × --duration-base) and disappears immediately.

The bubble is inverse in both themes: dark ink on light pages, light ink on dark pages, like the toast.

Responsive behaviour

  • Hover does not exist on touch screens, so a tooltip must never be the only place information lives; on (hover: none) devices it only appears on keyboard focus.
  • The bubble wraps at 16rem and is placed below (.tooltip--below) when the trigger is near the top of the viewport.
  • No breakpoint changes otherwise.

Theming

Reads --color-bg-inverse, --color-fg-inverse, --color-border-inverse (shortcut key outline), --radius-sm, --shadow-3 and --z-tooltip. The inverse pair flips with the theme, so no component override is needed.

Accessibility

Role and pattern

role="tooltip" on the bubble and aria-describedby on the trigger, following the APG Tooltip pattern. The trigger keeps its own accessible name (aria-label); the tooltip only adds a description.

Keyboard

KeyAction
TabFocusing the trigger shows the tooltip.
EscHides the tooltip without moving focus (WCAG 1.4.13 dismissible).
Shift+TabLeaving the trigger hides it.

Focus

Focus never enters the tooltip. The trigger shows the shared focus ring.

Labelling

Never put the only name of a control in a tooltip. The tooltip is announced as a description after the name, so keep it different from the label or omit it.

Contrast

Tooltip text

Motion

Fades and moves 4px over --duration-fast; with reduced motion it appears instantly (the 300ms delay remains, because it is a timing, not an animation).

Touch

Tooltips stay visible while the pointer moves onto them (WCAG 1.4.13 hoverable) and are absent on touch. Triggers keep the 44px target.

Content

  • A verb phrase or noun, sentence case, no full stop: "Delete task".
  • At most one short line; if it needs two sentences it belongs on the page.
  • Shortcuts use the platform's names: "Ctrl Z" on Windows and Linux, "⌘ Z" on macOS.
