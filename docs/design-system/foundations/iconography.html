Foundation · Iconography

Iconography

Six inline line icons on a 24-unit grid with a 2px stroke, coloured by currentColor and always labelled by the control that holds them.

WCAG 2.2 AAInline SVG6 icons

Overview

Tasks uses a handful of line icons, all drawn inline as SVG so they inherit colour from currentColor and need no icon font or sprite request. There is no external icon library; every icon on this page is one the mocks already draw.

  • Grid: 24 × 24 units with a 2-unit safe margin. Two small glyphs (the checkbox tick, 14 units; the done tick, 20 units) are drawn on their own grids because they sit inside fixed shapes.
  • Stroke: 2 units, round caps and joins, no fill (.icon sets all of this). Ticks use a 3-unit stroke so they read at small sizes.
  • Colour: currentColor only, so an icon always matches its label and theme. Status icons take their status colour from the parent (--alert-icon).

Illustration

88-unit illustrations built from six classes: .art-fill, .art-paper, .art-line, .art-line--quiet, .art-highlight, .art-ray.

Empty-state art is the only illustration. It uses the accent tint as a disc, the accent as line work, and --color-highlight (sun) for one spark. It is always aria-hidden: the title beside it carries the meaning.

Usage

  • One icon means one thing everywhere: the trash is always delete, the plus always add.
  • Icons accompany text; the only icon-only controls are delete (row) and Add task below 576px, both with an aria-label.
  • Never scale an icon with transform; pick a size class so strokes stay 2px.

Accessibility

  • Decorative and redundant icons: aria-hidden="true", no <title> (WCAG 1.1.1).
  • Meaningful icons that stand alone: the control, not the SVG, gets the name via aria-label.
  • Icons that carry meaning (status icons, the checked tick) meet 3:1 against their background (1.4.11); see the contrast pairs on the color page.
  • Under forced-colors: active, currentColor maps to the system text colour, so icons stay visible.

Tokens

Icons have no tokens of their own. Their size comes from the .icon--sm/md/lg classes (the --icon-size custom property in components.css), and their colour from the text colour of the parent, usually --color-fg-default, --color-fg-muted or a --color-*-icon status token, documented on the color page.
