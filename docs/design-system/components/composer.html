Composer

The composer is how every task begins: one field that asks "What needs doing?" and one Add task button. It keeps whatever was typed whenever a task could not be added.

WCAG 2.2 AAStatus: stableUsed in v1<form novalidate>

Overview

The composer is the first thing in the task card and has focus on load, except on touch devices (L2-022.3). Enter or Add task submits; the field clears and keeps focus so the next task can follow immediately (L2-001.3). The new row appears optimistically at the top of the list while the request is in flight (L2-004.1).

It is a specialised inline form: a text field (filled, large) inside a form field wrapper, a primary button that collapses to its icon below 576px, and an inline message under the card edge. Use it only for creating tasks; do not reuse it for search or editing.

Anatomy

  1. Form.composer: flex row, --space-3 padding, --space-2 gap, hairline bottom border.
  2. Field.input.input--filled.input--lg: 52px, sunken fill, 1.5px --color-border-strong edge (D2), 18px text. Hidden label "New task".
  3. Counter.field__count: appears from 160 characters (L2-002.3); red at 200/200.
  4. Add task.btn--primary.btn--lg.btn--collapse: plus icon and label; icon only below 576px.
  5. Message.message--error.composer__message under the form; hidden when empty.

Variants

One composer, two layouts by breakpoint. The button never changes meaning or name; only its label is hidden on phones.

SM and up: icon + "Add task". XS (under 576px): 52px square icon button, still named "Add task". In product code one .btn--collapse does both.

Sizes

One size: the composer is the large (52px) control by design, the most prominent target on the screen.

States

Every state from pages/states.composer. Focus is forced with data-state="focus"; motion is frozen.

There is no disabled or loading state: the composer stays usable while the list loads, while offline and after a load error (L2-008.6, L2-042); a failed add removes the pending row, puts the title back and shows "Couldn't add that task. Try again." as an error toast (L2-004.3).

Responsive behaviour

  • XS (under 576px): the field takes all the width left by a 52px square Add task button (.btn--collapse hides .btn__label); the accessible name stays "Add task" through aria-label.
  • SM and up: the button shows the plus and "Add task"; the field shrinks first, the button never wraps.
  • The field text is 18px at every size, above the 16px iOS zoom threshold (L2-028.3).
  • Rotating the device keeps the typed text (L2-028.4): the composer never re-renders its input on resize.

Theming

The composer has no tokens of its own: it composes --input-* (filled field), --btn-* (primary button) and the message tone. In dark, the filled field sits on --color-bg-surface-sunken (darker than the card), the focus halo is the deep accent tint, and the button flips to a light accent with dark label.

Accessibility

Role and pattern

A native <form novalidate> with one text input and a submit button. No ARIA widget pattern; the error is an role="alert" paragraph linked by aria-describedby.

Keyboard

TabField → Add task → first filter button.

Focus

Focused on load on pointer devices; not on touch, where focusing would open the keyboard unasked. Field focus is the accent edge plus halo; the button uses the shared 2px ring.

Labelling

Label "New task" (visually hidden, L2-029.3); button "Add task" in both layouts. Adding is announced as "Task added" in the page's polite live region (L2-025.2); errors are announced by the role="alert" message. The counter is aria-hidden; reaching 200 is signalled by maxlength and the red count.

Code

// Submit: optimistic add, keep focus, keep text on failure
form.addEventListener('submit', (e) => {
  e.preventDefault();
  const title = input.value.trim();
  if (!title) { showError('Enter a task title.'); form.classList.add('composer--shake'); return; }
  input.value = '';
  input.focus();
  store.add(title).catch(() => { input.value = title; });
});
form.addEventListener('animationend', () => form.classList.remove('composer--shake'));
