List

A list shows similar items one per row, with an optional icon, one line of metadata and a trailing value.

WCAG 2.2 AAStatus: stableNot used in v1

Overview

A list shows a set of similar items, one per row: mock pages, settings, search results. It is the generic sibling of the task item, which carries the product's own row with checkbox, editable title and delete.

  • Use a list when items are read top to bottom and have at most a title, one line of metadata and one trailing value.
  • Use a table when people compare values across columns; use a description list for key–value pairs about one thing.
  • Interactive rows contain exactly one link or button that fills the row; the <li> itself is never the control.

v1 renders only the task list; the generic list is part of the system for the launcher and future screens, and its look is taken from the mock launcher tiles and task rows.

Anatomy

  1. Leading icon (optional)20px, --color-fg-muted, aria-hidden.
  2. Title.list__title, medium weight; wraps, never truncates.
  3. Metadata (optional).list__meta, 14px --color-fg-muted.
  4. Trailing (optional).list__trailing: a count, date or chevron.

Sizes

Lists have one density: 56px minimum rows (48px plus padding) so every interactive row is a 44px target.

States

Only interactive rows have states. Hover and focus are forced with data-state; selection uses aria-current for navigation or aria-selected inside a listbox.

Responsive behaviour

  • Lists are a single column at every breakpoint and take the width of their container.
  • Titles and metadata wrap; the trailing value stays on the first line's right edge and never shrinks below its content.
  • On hover: none devices nothing is hidden behind hover; the chevron marks interactive rows.

Theming

Rows read --color-border-default (divider), --color-bg-subtle (hover), --color-accent-subtle (current/selected), --color-fg-muted (icon, metadata, trailing). In dark the divider and hover darken with the surface and the selected tint becomes deep sea. Override the tokens on .list to re-skin a list; never colour individual rows.

Accessibility

Role and pattern

A native <ul>/<li>; screen readers announce "list, 3 items". Interactive rows hold a single <a> or <button> (.list__action) whose text is the title and metadata. A selectable list that acts as one widget uses the APG Listbox pattern instead, with aria-selected.

Keyboard

KeyAction
Tab / Shift+TabMoves between row links in order.
EnterFollows the link or activates the button.
SpaceActivates a button row (links ignore Space).

Focus

The ring is drawn inset (outline-offset: -2px) so it stays inside the card's rounded clip.

Labelling

The visible title is the name. Do not add aria-label that differs from the text; icons are aria-hidden. A list that needs a heading gets one immediately before it, or aria-labelledby.

Motion

Only the hover background changes, with no transition. Nothing to reduce.

Touch

Interactive rows are at least 56px tall and full width, well above the 44px target.

Content

  • Titles are nouns or short phrases in sentence case: "Load error", not "LOAD ERROR" or "Click to view load error".
  • Metadata adds one fact: a count, a state, a date. Numbers use digits ("5 tasks").
  • Order by what people look for: newest first for tasks, the fixed product order for navigation.
