Tables and lists

The list is the product: newest first, nothing jumps, nothing is truncated.

Overview

The task list is the product. It is a plain <ul> of task rows in one card: newest first, a completed task stays where it is, long titles wrap, and every row has the same three controls in the same order. A table is for comparing values across columns, which v1 never needs.

Components: Task item, List, Table, Checkbox, Skeleton, Empty state.

When to use

ContentUseWhy
Items with one title and a stateTask listOne column; the row is the unit of action.
Items with a title and secondary text or metadataList (two-line)Scannable; no column alignment needed.
Records compared across several attributesTableColumns align values; sort by column. Not in v1.
Key–value facts about one thingDescription listNot in v1.

Structure

Newest first; completed tasks stay in place; the long title wraps and the controls stay aligned; the hovered row reveals delete.
  1. Checkbox: 44px target, round 24px box, accessible name = the title.
  2. Title: a button that starts editing; wraps onto as many lines as it needs (L2-027.6).
  3. Delete: icon button named "Delete title"; revealed on hover or focus on pointer devices, always visible on touch (L2-028.2).
  4. Separator: hairline --color-border-default; the last row has none.

Responsive behaviour

  • The list is one column at every breakpoint; only the card's width changes (L2-027).
  • At 320px with a 200-character title, the title wraps and the row grows; the checkbox and delete stay top-aligned to the grid cell centre and never overlap text (L2-027.6).
  • (hover: none): delete is always visible. (hover: hover): revealed on row hover or :focus-within.
  • If a future table has four columns or fewer, it may stack into label–value cards below MD (.table--stack); otherwise it scrolls inside .table-wrap.

Accessibility

  • Semantics: <ul> with <li> (L2-029.1); each checkbox is a native input named with the title (L2-029.2); icon buttons include the title in their name (L2-029.5).
  • Keyboard: Tab moves checkbox → title → delete per row; Space toggles; Enter on the title edits (L2-023.3).
  • After deleting by keyboard, focus goes to the next row, else the previous, else the composer (L2-031.3).
  • Completed state is a tick, a strike-through and muted text, never colour alone (L2-030.6).

Content

  • Titles are the person's words, shown exactly as typed (trimmed), up to 200 characters. Never truncate with an ellipsis.
  • Accessible names: "Edit title", "Delete title"; the checkbox is just the title.
  • Counts use digits and the word "left": "3 left", or "All done".
