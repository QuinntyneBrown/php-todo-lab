Skip link

The first focusable element: jumps keyboard users past repeated content. Not needed in v1 yet.

Overview

A skip link is the first focusable element on a page. It is hidden until it receives keyboard focus, then lets people jump past repeated content straight to the main region (WCAG 2.4.1).

Not used in v1. The page has no repeated navigation before <main>: the first focusable control is already the composer input (L2-022.3 gives it focus on load). Add a skip link as soon as anything (a top bar, a sidebar) precedes the main content. This documentation site uses one on every page (D22).

Anatomy

  1. LinkRaised surface, --shadow-3, semibold link text, fixed at the top-left with --z-tooltip; translated off-screen until focused.

Responsive behaviour

  • Identical at every width; it overlays the top-left corner with a 16px inset.
  • Touch users rarely see it; it costs nothing when unused.

Theming

Reads --color-bg-surface-raised, --color-fg-link, --shadow-3, --radius-md and --z-tooltip.

Accessibility

Role and pattern

A plain <a href="#main"> as the first element in <body>. Give the target tabindex="-1" so focus moves into it in every browser. It is visually hidden with a transform, not display: none, so it stays focusable.

Keyboard

KeyAction
Tab (first press)Reveals the link.
EnterMoves focus to <main>.
Tab againHides it and continues to the next control.

Focus

Shared focus ring plus the raised surface; it never covers the element it skips to.

Labelling

Name the destination: "Skip to tasks" or "Skip to content".

Contrast

Link on raised surface
Focus ring

Motion

No transition: it appears and disappears instantly.

Touch

At least 40px tall (padding around one line); not usually reached by touch.

Content

  • "Skip to" plus the name of the main region, sentence case.
  • One skip link; add more only when a page has several large repeated blocks.
