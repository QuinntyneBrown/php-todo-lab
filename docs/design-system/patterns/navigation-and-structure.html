Navigation and structure

One route, five regions in a fixed order, and a filter that lives in the URL.

Overview

Tasks is one screen with one flow (L2-022). There is no menu, no settings page, no second route: unknown paths redirect to /. "Navigation" in v1 means three things: the fixed order of regions on the page, the filter that changes what the list shows and is mirrored in the URL, and the keyboard order through it all.

Components: App header, Button group (the filter), Card, Layout primitives, Skip link. Sidebar navigation, Tabs, Breadcrumb and Pagination exist for a future multi-page product and are not used in v1.

States

Filter All (URL /), Active (/?filter=active), Done (/?filter=done), and nothing to clear.
  • Selecting a filter updates aria-pressed, slides the indicator (200 ms) and replaces the URL query without a reload; back and forward restore the filter; reload keeps it (L2-006.3, L2-006.5).
  • ?filter= is omitted for All. Any other value falls back to All.
  • A task completed under Active leaves the list after its completion animation (L2-006.6).

Responsive behaviour

BreakpointLayout (L2-027)
XS < 576pxFull-width column, 16px side gutters, 48px ring; filter spans the full width on its own row, counts hidden (still in the accessible names); Clear completed below it, right-aligned.
SM 576–767pxColumn up to 560px, centred.
MD 768–991pxColumn 640px, centred, 40px from the top; the card is a raised surface with rounded corners.
LG / XL ≥ 992pxColumn stays 640px and sits 8vh from the top; the layout never stretches.

Tokens: --layout-container-max (35rem → 40rem at MD) and --layout-offset-top (24px → 40px → 8vh) change at the breakpoints, so .container needs no media queries of its own.

Accessibility

  • Landmarks: header, main; one h1 (the weekday); the card is a labelled section (L2-029.1).
  • Focus on load: the composer, except on touch devices (L2-022.3).
  • Tab order: composer, Add task, the three filter buttons, Clear completed, then each row's checkbox, title, delete in list order (L2-023.4).
  • Shortcut: / from anywhere outside a text field focuses the composer (L2-023.1).
  • Filter names include the count: "Active, 3" (L2-029.4, L2-007.6).
  • Clear completed with nothing to clear is aria-disabled="true", not disabled, so it stays discoverable (L2-017.2).

Content

  • Filter labels are single words: All, Active, Done. URL values are active and done, matching the labels, not the API's completed.
  • The group's name is "Show tasks".
  • The page title is the product name; the visible heading is the weekday in the user's locale, the date below it ("Wednesday", "7 October", L2-022.4).
