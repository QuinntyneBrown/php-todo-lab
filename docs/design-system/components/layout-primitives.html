Layout primitives

Container, grid, stack and cluster: the four primitives that hold every layout decision.

WCAG 2.2 AAStatus: stableUsed in v1

Overview

Four primitives place everything else. They hold the layout decisions (column width, gutters, margins, gaps) so components never set their own outer spacing or write their own media queries.

  • .container is the product's task column (L2-027): full width with 16px side gutters on phones, 560px at SM, 640px at MD and up, centred, with a top offset that grows to 8vh at LG and bottom clearance for the toast.
  • .grid is the 4 / 8 / 12-column grid. v1 is a single column, so the grid is used by this documentation and by future multi-column screens.
  • .stack spaces children vertically; .cluster wraps children horizontally (filter rows, button groups).

Anatomy

  1. MarginViewport edge to content: --layout-margin (16 / 32 / 48px). The task column keeps 16px at every width.
  2. GutterBetween columns: --layout-gutter (16 / 24 / 32px).
  3. Column--layout-columns equal tracks (4 / 8 / 12).

Responsive behaviour

  • Mobile first: the base styles are XS; tokens.css updates --layout-container-max, --layout-offset-top, --layout-columns, --layout-gutter and --layout-margin at 48rem and 62rem. Components read the tokens instead of writing their own media queries (D18).
  • The column never stretches beyond 640px (L2-027.4) and nothing scrolls horizontally from 320 to 1920px (L2-027.5).
  • The bottom padding (--layout-safe-bottom: 96px + env(safe-area-inset-bottom)) keeps the last row clear of the fixed toast (L2-028.5).
  • Breakpoints are written in rem so they follow the user's font size; custom properties cannot be used inside @media, so the values are repeated there by convention.

Theming

Primitives read only layout and spacing tokens (--layout-*, --space-*); no colour. A different product shell changes --layout-container-max and the offsets, not the classes.

Accessibility

Role and pattern

Primitives are presentational divs; landmarks come from the elements you put them on (<main class="container">). There is no ARIA pattern.

Keyboard

KeyAction
TabFollows DOM order. Never reorder visually with order or grid placement so that it disagrees with DOM order (WCAG 2.4.3).

Focus

Primitives are not focusable. scroll-padding is not needed in v1 because nothing is sticky; add it when a sticky header appears (WCAG 2.4.11).

Labelling

None; name the landmark or region that uses the primitive.

Contrast

Not applicable: primitives draw nothing.

Motion

None.

Touch

Reflow to 320px (WCAG 1.4.10) and 200% zoom (L2-030.3) is guaranteed by fluid columns and minmax(0, 1fr) tracks, so long titles wrap instead of pushing the layout wider (L2-027.6).

Content

  • Prose inside a container is capped at --layout-measure (65ch); empty-state text at 30ch.
  • Do not justify text or force line breaks to fit a column; let it wrap.
