Content

Overview

Tasks speaks plainly. Copy is active, short, sentence case, and uses one name for each thing: task in the UI, Add task, Undo, Clear completed (L2-025). Errors say what happened and what to do next, and never apologise. Every user-facing string lives in one typed constants file (ui-strings.ts) so it can be reviewed and later localised (L2-025.4).

Voice and tone

HonestYou're offline. Changes will fail until you reconnect.Don't worry, we'll sync later. (It won't.)
  • No exclamation marks, no "Oops", no "Sorry" (L2-025.1, L2-025.3).
  • Second person, present tense: "You have 500 tasks."
  • Contractions are fine ("Couldn't", "You're"); they read as spoken.

Sentence case and naming

  • Sentence case everywhere: buttons, headings, toasts, labels. "Clear completed", not "Clear Completed".
  • One name per thing. It is always a task (never todo, item or entry); finishing it is complete in announcements and done in the filter.
  • Filters are one word each: All, Active, Done.
  • The task's own title is user content: show it exactly as typed, including its case, and wrap it, never truncate.

Button verbs and echoes

A button is a verb phrase. The same verb comes back in the toast and the announcement, in the past tense (L2-025.2): "Add task" produces "Task added".

  • Icon-only buttons still have words: aria-label="Delete Call mom" names the verb and the object (L2-029.5).
  • Undo is always the word "Undo"; it is offered for every destructive action instead of a confirmation.

Numbers, dates and counts

  • Numerals, not words: "3 tasks cleared", "2 left". Counts use tabular figures so they do not jump.
  • Singular at 1: "1 task cleared", "1 left" (L2-025). Pluralise with the locale's plural rules, not by appending "s".
  • Zero remaining reads "All done" in the header, not "0 left".
  • Limits are stated as numbers: "You have 500 tasks."; the counter shows "165/200" without spaces and turns danger-coloured at the limit.
  • The header date is the weekday ("Wednesday") over the day and month ("7 October"), both formatted in the user's locale (toLocaleDateString with weekday: 'long' and day: 'numeric', month: 'long'). No year: the page is always today.
  • Filter names carry their counts for assistive technology: "Active, 3".

Error message formula

What happened + what to do. Name the thing, use the past tense for the failure, and give a next step when there is one.

  • Toasts for failed background actions: "Couldn't <verb> that task." Add "Try again." only when retrying can help.
  • Field errors sit at the field, are linked with aria-describedby, and keep what the person typed.
  • Server validation messages (422) are shown as sent, at the field (L2-004.4).

Usage

Accessibility

  • Accessible names follow the same rules as visible text: verb first, object named ("Edit Call mom").
  • Announcements are short and past tense; the live region is polite, errors use role="alert" (WCAG 4.1.3).
  • The placeholder is a question, never the label (WCAG 3.3.2); the label "New task" is always present.
  • Error text names the field's problem and the fix (WCAG 3.3.1, 3.3.3).

Tokens

Content has no tokens. Text styles (--text-*) are on the typography page.
