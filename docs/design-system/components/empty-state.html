Empty state

What the list shows when there is nothing in it: a small illustration, a title and the next step.

WCAG 2.2 AAStatus: stableUsed in v1

Overview

An empty state fills the list area when there is nothing to show, and says why and what to do next. The product has three: first run (L2-008.2), no active tasks under the Active filter (L2-006.4), and nothing completed under the Done filter (L2-006.5). Each is an illustration, a title and one sentence; the composer directly above is the action, so v1 empty states have no button.

  • Use an empty state when a successful load returns nothing. Use the banner when the load failed; never an empty state.
  • Use the error page only when the whole screen cannot render.
  • When everything is complete under All, the list still shows the done tasks; the header ring says "All done", not an empty state.

Anatomy

  1. Illustration88px inline SVG from the art palette: accent-subtle disc, accent line work, one sun dot. aria-hidden.
  2. Title--text-h2 (24px display, 800), tight tracking. A heading in the page outline.
  3. TextOne sentence, muted, capped at 30ch, centred.

Sizes

Two sizes. Full (48px block padding, 88px art, 24px title) fills a list. Compact (24px padding, 56px art, 20px title) fits a panel or table body.

Responsive behaviour

  • Centred in the card at every breakpoint; 24px side padding keeps the text clear of the card edge at 320px.
  • The 30ch cap keeps the sentence to one or two lines from 320px to 1920px.
  • The illustration never scales with the viewport; switch to compact in narrow panels instead.

Theming

The illustration uses six art classes mapped to semantic tokens: .art-fill (--color-accent-subtle), .art-line (--color-accent), .art-line--quiet (--color-border-strong, dashed), .art-highlight and .art-ray (--color-highlight, sun) and .art-paper (--color-bg-surface). New illustrations draw with these classes only, so they follow both themes automatically.

Accessibility

Role and pattern

A heading and a paragraph; the art is aria-hidden. No ARIA pattern applies. When a filter change produces the empty state, the polite live region announces the count ("0 active"), not the empty-state text.

Keyboard

KeyAction
TabReaches the action, if any. v1 empty states have none.

Focus

Never moves focus. On first run focus is already in the composer (L2-022.3).

Labelling

The title is an h2 under the page's single h1 (the weekday, L2-029.1).

Contrast

Title on card
Text on card
Sun accents (decorative)

Motion

None. Empty states appear without animation; when the last row leaves, its 250ms exit plays and the empty state replaces the list.

Touch

Only the optional action is a target (44px).

Content

  • Title: the situation in two or three words, sentence case, no full stop: "Nothing here yet", "All clear", "Nothing completed yet".
  • Text: one sentence telling the person how to get content here: "Type a task above and press Enter." "Tick a task and it will show up here."
  • No "Oops", no exclamation marks, no blame ("You haven't…") (L2-025).
