Spacing

A 4px grid in rem: small steps inside components, larger steps between them, and 44px targets everywhere.

WCAG 2.2 AAStatus: stableSource: tokens/tokens.css
  • Overview
  • Scale
  • Inside and between
  • Padding by size

Overview

All spacing sits on a 4px grid, expressed in rem. The mocks used 23 distinct spacing values, seven of them off-grid (2, 3, 6, 10, 14, 17, 18px); each was snapped to the nearest step that kept the layout's intent (D11). Components use --space-6 or less inside themselves; the page uses --space-6 and above between blocks.

The scale

Step numbers are multiples of 4px: --space-4 is 16px. --space-0-5 (2px) is for hairline gaps only.

Inside and between

Two rules decide every gap:

  • Inside a component: 4–24px. Icon to label 8px (--space-2), the segmented track's inset 4px, a task row's padding 4px around a 44px target, card-edge padding 12px (composer, toolbar), field padding 16px.
  • Between components: 16px and up. The offline notice sits 16px above the card; the header has 20px under it; the list leaves 96px (--space-24) at the bottom so the toast never covers the last task.
  • Related controls sit closer than unrelated ones: the composer's field and button are 8px apart; the filter and Clear completed are pushed to opposite ends.

Padding by component size

Control heights come in three steps. Every product control is at least 44px tall (L2-028.1); 36px exists only where a larger parent is the target.

Usage

  • Use a token for every margin, padding and gap; never a pixel value. If a design needs 6px, it needs 4 or 8.
  • Spacing never scales with the viewport; a breakpoint changes the token (for example --layout-offset-top), not a vw value.
  • Prefer gap on a flex or grid parent over margins on children.
  • Optical exceptions are allowed only as calc() of tokens (the counter's 72px right padding is --space-16 + --space-2).

Accessibility

  • Targets keep 44px even when visually small: the 24px checkbox sits in a 44px .checkbox__control (L2-028.1, WCAG 2.5.8).
  • Spacing in rem grows with text at 200% zoom, so controls never overlap text (L2-027.6).
