Design system

Tasks design system

The visual and interaction language of Tasks, the one-screen to-do app: a calm ink-and-sea palette, a confident display face for the day, and one celebratory moment when a task is done. Every decision here was mined from the mocks in docs/mocks, normalised into tokens and checked for WCAG 2.2 AA in both themes.

How to use

  1. Link the CSS. tokens/tokens.css first, then assets/components.css. Nothing else is required; assets/ds.css and ds.js only style this documentation.
  2. Use the classes. Copy the markup from any component page's Code section. State lives in native attributes and ARIA (disabled, aria-pressed, aria-invalid, aria-busy); data-state is for documentation only.
  3. Consume the tokens. tokens/tokens.json is a DTCG export generated from tokens.css (dark values under $extensions). In the Angular app, frontend/src/styles/tokens.scss should mirror tokens.css; component SCSS reads semantic tokens only (L2-026.4).
  4. Re-skin with component tokens. Override --btn-*, --input-*, --toast-* and friends on a scope; never edit a component rule for a one-off.
  5. Check contrast when you change a colour. Add the pairing to tokens/contrast-pairs.json and run the contrast checker (see README).
