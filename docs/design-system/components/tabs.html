Tabs

Switch between panels on one page. Not used in v1: the task filter is a segmented button group (L2-029.4).

WCAG 2.2 AAStatus: readyNot used in v1

Overview

Tabs switch between panels of related content on one page without leaving it. Exactly one tab is selected and its panel is shown.

Not used in v1. The All / Active / Done switch looks like tabs but is a filter on one list: the list stays the same element, only its rows change, and the choice is mirrored in the URL. L2-029.4 therefore specifies a role="group" of buttons with aria-pressed (or a radio group), which is the segmented button group. Tabs are kept for future screens with genuinely separate panels (D22).

  • Use tabs for two to six sibling panels with short labels.
  • Do not use tabs to filter one list, to step through a sequence (use a stepper), or for navigation between pages (use links).

Anatomy

  1. Tab listrole="tablist" with a hairline baseline.
  2. Selected indicator2px --color-accent underline plus semibold label.
  3. Tab44px tall, label and optional count.
  4. Panelrole="tabpanel", focusable, 16px block padding.

Responsive behaviour

  • All widths: the list scrolls horizontally when it overflows; add a fade at the clipped edge if more than one tab is hidden.
  • Below SM, prefer three or fewer tabs; if more are needed, a <select> may replace the tab list.
  • Tabs keep 44px height at every breakpoint (L2-028.1).

Theming

Reads --color-fg-muted, --color-fg-default, --color-accent, --color-border-default, --color-border-strong (hover underline) and, for pills, --color-bg-surface-sunken, --color-bg-surface-raised and --shadow-1.

Accessibility

Role and pattern

APG Tabs pattern with automatic activation: arrow keys move focus and select. role="tablist" (labelled), role="tab" with aria-selected and aria-controls, role="tabpanel" with aria-labelledby. Roving tabindex: only the selected tab is in the tab order.

Keyboard

KeyAction
TabMoves into the tab list (to the selected tab), then to the panel.
← / →Selects the previous / next tab, wrapping.
Home / EndSelects the first / last tab.
Disabled tabsAre skipped by arrow keys.

Focus

Underline tabs draw the ring inset (negative offset) so it is not clipped by the scrolling list; pill tabs use the standard 2px offset. The panel is focusable so keyboard users can reach content that has no controls.

Labelling

The tab label is its name; counts are part of it ("Active 3"). Give the tab list an aria-label describing the set.

Contrast

Unselected label
Selected indicator
Pill label on track

Selection is shown by the underline (or raised pill) and the heavier weight, never by colour alone.

Motion

Colour and underline transition over --duration-fast; instant with reduced motion.

Touch

44px tall; tabs are at least 44px wide because of their padding.

Content

  • One or two words in sentence case, nouns not verbs: "Active", not "Show active".
  • Counts are bare numbers after the label.
  • Keep the same order and names everywhere (WCAG 3.2.4).
