Textarea

A textarea takes text that runs over several lines, such as notes. It shares every token and state with the text field.

WCAG 2.2 AAStatus: readyNot used in v1Native <textarea>

Overview

Use a textarea when people may write more than one sentence. Task titles are a single line of up to 200 characters, so v1 uses a text field and lets long titles wrap in the row instead (L2-027.6). The textarea is ready for a future notes field.

Anatomy

  1. LabelAlways visible for a textarea.
  2. Containertextarea.input: minimum two lines (88px), 12px vertical padding, vertical resize.
  3. Hint or messageLinked with aria-describedby.

Variants

71/1000

Auto-grow uses field-sizing: content where supported and falls back to the fixed size. The counter sits under the field, never inside it.

Sizes

One size: medium text and padding; height comes from rows or content.

States

VariantDefaultHoverFocusInvalidRead-onlyDisabled
Textarea

Both themes

Responsive behaviour

  • Full width of its container at every breakpoint; only vertical resize, so it cannot cause horizontal scroll.
  • Text stays 18px for iOS (L2-028.3). On phones prefer auto-grow over the resize handle, which is hard to grab.

Theming

Identical to the text field: --input-bg, --input-border, --input-height (here used as the base for the two-line minimum).

Accessibility

Role and pattern

Native <textarea>; no role. Errors via aria-invalid and aria-describedby.

Keyboard

KeyAction
TabInto and out of the field (Tab never inserts a tab character).
EnterNew line. Never submits the form.

Focus

Accent edge plus 3px halo, as the text field.

Labelling

A visible <label for>; hint and counter in aria-describedby. Announce the counter only near the limit, through a polite live region, not on every keystroke.

Contrast

Text on surface
Edge on card
Hint on card

Motion

Edge and halo transition over 150ms; none under reduced motion.

Touch

Minimum 88px tall; the whole area is the target.

Content

  • Label it with a noun ("Notes"); mark it optional in the hint, not with an asterisk.
  • State the limit once in the hint; show the counter as "71/1000".

  <label class="field__label" for="notes">Notes</label>
  <textarea class="input textarea--auto" id="notes" maxlength="1000" aria-describedby="notesHint"></textarea>
